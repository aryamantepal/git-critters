        What happens when I click it?
        
    
          
  1. GitHub opens with one small workflow file already filled in.
    2. 
          
  2. You commit it. Choose “Create a new branch” if you'd rather review it as a pull request.
    3. 
          
  3. Within a minute, the workflow draws your critter, or an egg if you left “Start from an egg” on, and adds it to the top of your README, or in place of a git-koi koi if you have one.
    4. 
        

        
An egg starts out uncracked and cracks as you make contributions. After  of them since you added the workflow, it hatches into the critter you picked. With “Surprise me”, the critter is chosen from your username and you only find out which one it is when it hatches. Turn “Start from an egg” off to get the critter straight away.

        
The workflow also runs every night, just after midnight UTC. It reads your public GitHub activity and redraws the critter, and it commits to your profile repo whenever the critter changes. That adds a few hundred KB to the repo's history each time. If nothing has changed for a while, it adds an empty commit now and then, so GitHub doesn't switch the nightly run off.

        
There's nothing to sign in to here, and nothing to install. To remove it, delete the workflow, critter.gif and the block it added to your README.
